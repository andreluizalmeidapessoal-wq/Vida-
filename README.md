# Vida

App web (PWA) simples para organizar **finanças, foco e academia** em um só lugar.
Código aberto. Sem login, sem servidor, sem nuvem: **todos os dados ficam só no seu aparelho** (IndexedDB).

## Instalar (usuário)
Abra o endereço do app no Chrome do Android → menu ⋮ → **Instalar app**.

## Rodar local
`python3 -m http.server 8000` e abra http://localhost:8000

## Privacidade
Nenhum dado é enviado a lugar nenhum. Use "Salvar backup" para guardar uma cópia.
Se limpar os dados do navegador ou perder o celular, os dados se perdem sem backup.
